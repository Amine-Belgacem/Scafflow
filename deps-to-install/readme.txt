Setup Instructions

1. Run GraphicsMagick-1.3.45-Q16-win64-dll.exe to install GraphicsMagick.

2. Run gs10051w64.exe to install Ghostscript.

3. When installing Ghostscript, keep the default installation folder:
   C:\Program Files\gs\gs10.05.1

4. Copy the file pathset.bat into:
   C:\Program Files\gs\gs10.05.1\bin

6. Right-click pathset.bat and select Run as administrator.

7. When prompted, type y to confirm.

This will add the Ghostscript bin folder to your system PATH automatically.
